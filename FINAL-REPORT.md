# AI Support Bot — итоговый отчёт

## Результат

Собран демонстрационный Telegram‑помощник для цифровых услуг. Он ищет подтверждённый фрагмент в локальной базе знаний, показывает источник и уровень уверенности, а при значении ниже `0.65` создаёт обращение для человека. Все данные синтетические.

## Проверено

- `14 passed` — полный набор автоматических тестов;
- демонстрационный прогон: 10 вопросов, 7 подтверждённых ответов, 3 передачи человеку;
- Python‑модули успешно компилируются;
- HTML открывается без сервера и внешних библиотек;
- интерактивный пример переключает оба маршрута;
- ширины 360, 768 и 1440 px не имеют горизонтального выхода;
- поддержаны клавиатурный фокус и `prefers-reduced-motion`.

## Состав

- `app/` — сервис ответа, база знаний, SQLite, Telegram‑обработчики и конфигурация;
- `knowledge_base/faq.json` — пять синтетических записей;
- `tests/` — тесты механизма, границы, базы и адаптера;
- `reports/support_demo.json` — воспроизводимый отчёт демонстрации;
- `index.html` и `case-study.html` — автономный портфолио‑кейс;
- `DESIGN.md` — зафиксированная дизайн‑система.

## Граница реального запуска

Живой Telegram‑запуск не выполнялся: пользовательские токены и идентификаторы менеджеров не передавались. Для запуска нужно создать `.env` по `.env.example`; секреты не входят в архив и HTML.
