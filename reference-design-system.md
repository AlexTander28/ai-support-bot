# Reference Design System — AI Support Bot

## Основа

- **R09 Shader Development Studio** — метафора работающего ретро-компьютера, CRT-ритм, serif + mono, загрузочная последовательность.
- Пользователь утвердил направление **A — Аналоговый AI-терминал**.
- Не копируются фирменный компьютер, логотип, WebGL-сцена, фиолетовый свет и тексты источника.

## Design Read

Experience/Read-кейс для работодателя: контролируемая AI-автоматизация раскрывается как диагностический терминал, где вопрос, найденный источник, confidence и решение видны одновременно.

## Токены

- `background`: `#11100F`
- `surface`: `#181715`
- `text`: `#F1ECE2`
- `muted`: `#999286`
- `confidence`: `#E2A93B`
- `verified`: `#58A66A`
- `handoff`: `#D64B45`
- `line`: `#35312C`
- Display: Georgia/STIX-like serif fallback; data/UI: Consolas; body: Arial.
- Радиус: `0`; линии и отступы создают структуру без карточной россыпи.

## Композиция

- Первый экран: вопрос слева, системное решение справа, между ними измерительная шкала confidence.
- Ниже: база знаний, два проверяемых маршрута, журнал, архитектура и тесты.
- На mobile блоки идут строго в порядке вопрос → источник → решение; критический смысл не зависит от одновременного просмотра колонок.

## Signature

**Confidence tape:** горизонтальная перфорированная лента, которая заполняется до фактического значения и физически переводит карточку либо в `ANSWER`, либо в `HANDOFF`.

## Motion

- Вопрос токенизируется, категория фиксируется, источник подсвечивается, затем заполняется confidence tape.
- Ниже `0.65` красная ветка передаёт обращение человеку; выше порога зелёная ветка показывает подтверждённый ответ.
- Только transform/opacity; слабые scanlines статичны при reduced motion.

## Запреты

- Фиолетовые градиенты, тяжёлый WebGL, сильная VHS-деформация, glow, фальшивые нейросетевые графики.
- Ответ без источника, неподтверждённые цены/сроки, английский интерфейс вне кода и названий технологий.
